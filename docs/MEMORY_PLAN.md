# CareerPilot AI — Memory Plan

> CareerPilot should remember useful career context — not everything.

## Guiding Principles

- Memory must have a **clear purpose**.
- Avoid storing unnecessary personal information.
- Do **not** blindly save every conversation.
- Store only what directly improves future career guidance.

## What to Remember

| Memory | Purpose | Source |
|--------|---------|--------|
| Target role | Grounds all analysis and mentoring | Career goal form |
| Career goal | Long-term direction | Career goal form |
| Education | Context for realistic roadmaps | Career profile |
| Experience level | Calibrates interview + roadmap difficulty | Career profile |
| Skills | Baseline for gap analysis | Resume analysis + profile |
| Skill gaps | Focus for roadmap + mentoring | Skill gap analysis |
| Roadmap | Current plan the user is following | Roadmap generator |
| Completed roadmap tasks | Progress tracking | User updates |
| Interview weaknesses | Targeted interview prep | Mock interview feedback |
| Resume recommendations | Ongoing resume improvement | Resume analyzer |
| Important career preferences | Personalize guidance (e.g. remote, location, industry) | Profile / chat |

## What NOT to Store

- Raw conversation logs beyond what is needed for short-term context.
- Sensitive personal data unrelated to career guidance.
- Anything the user has not knowingly provided for career purposes.

## Retention & Scope

- Memory is scoped **per user** and protected by authentication.
- Conversation history kept only as long as needed for context continuity.
- Users should be able to view and delete their career data.
