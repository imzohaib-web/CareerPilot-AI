# CareerPilot AI — Project Specification

> Your Personal AI Career Mentor & Interview Coach

## Product Vision

CareerPilot AI is an AI-powered career-readiness platform that helps students understand their current career readiness, identify skill gaps, improve resumes, prepare for interviews, create personalized learning roadmaps, and receive context-aware career guidance.

## Hackathon Context

- **Hackathon:** Alibaba Cloud AI Hackathon Pakistan 2026
- **Theme:** AI for Pakistan's Future
- **Team:** 2 developers
- **Training completed:** 19–20 August 2026 (Qoder, Qoder IDE, Alibaba Cloud, Alibaba Cloud Model Studio / Qwen, MCPs, Agent Skills, AI Memory)
- **Build window:** 29 August – 4 September 2026 (7 days)
- **Repository:** https://github.com/imzohaib-web/CareerPilot-AI

## Target Users

- University students
- Fresh graduates
- Early-career developers
- Students preparing for internships/jobs

## Core Problem

Students often do not know:

- Whether their resume is job-ready
- Which skills they are missing
- What they should learn next
- How to prepare for interviews
- Which projects would strengthen their profile
- How to create a realistic career plan

## Core Solution

CareerPilot combines:

1. AI Resume Analyzer
2. Skill Gap Analysis
3. Personalized Learning Roadmap
4. AI Career Mentor
5. AI Mock Interview
6. Progress Tracking

## Hackathon MVP

### Must Have

- Authentication
- Career Profile
- Career Goal
- Resume Upload
- AI Resume Analysis
- Skill Gap Analysis
- Personalized Roadmap
- AI Career Mentor
- Mock Interview
- Interview Feedback
- Student Dashboard
- Progress Tracking

### Bonus

- GitHub analysis
- MCP-powered tools
- Lightweight RAG
- LinkedIn suggestions
- Voice interview
- AI cover letter
- Daily challenges

## Non-Goals

Do not build during the hackathon sprint:

- Mobile application
- Payment system
- Full job marketplace
- Social network
- Large admin panel
- Custom foundation model
- Complex microservice architecture
- Unnecessary AI infrastructure

## Guiding Principles

- RELIABILITY > COMPLEXITY
- MVP COMPLETENESS > FEATURE COUNT
- CLARITY > ABSTRACTION
- SECURITY > CONVENIENCE
- REAL AI VALUE > AI BUZZWORDS
