# CareerPilot AI — Demo Flow

> Goal: show a complete, believable student journey in under 5 minutes.

## Narrative

A university student, **Ayesha**, wants to become a Frontend Developer but doesn't know if she's ready or what to learn next. CareerPilot AI guides her end-to-end.

## Script

1. **Hook (20s):** State the problem — students don't know if they're job-ready or what to learn next.
2. **Sign up + Profile (30s):** Register, set career goal = Frontend Developer.
3. **Resume Analysis (45s):** Upload resume → live AI analysis → readiness score, strengths, improvements.
4. **Skill Gap (40s):** Show gaps vs Frontend Developer (e.g. missing TypeScript, high priority).
5. **Roadmap (40s):** Generate a personalized phased roadmap tied to the gaps.
6. **AI Mentor (45s):** Ask "What should I focus on first?" → mentor answers grounded in Ayesha's gaps/roadmap.
7. **Mock Interview (50s):** Start a short interview, answer one question, show scored feedback.
8. **Dashboard (30s):** Progress overview tying it all together.
9. **Close (20s):** Recap value + Alibaba Cloud / Qwen powering the AI.

## Reliability Checklist

- Use a pre-tested resume file.
- Warm up the Qwen connection before the demo (hit `/api/ai/test`).
- Have a recorded backup video in case of live failure.
- Hardcode nothing visible; real AI responses only.
- Verify the demo account's data is populated and correct before presenting.
