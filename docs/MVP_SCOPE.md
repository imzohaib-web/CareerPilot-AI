# CareerPilot AI — MVP Scope Control

Build window: **29 August – 4 September 2026** (7 days). The deadline is a hard constraint.

> **Core principle: a smaller complete product is better than a large incomplete product.**
>
> **Rule: do not implement a bonus feature if it puts a must-have feature at risk.**

## MUST HAVE

- Authentication
- Career Profile
- Career Goal
- Resume Upload
- AI Resume Analysis
- Skill Gap Analysis
- Personalized Roadmap
- AI Career Mentor
- Mock Interview
- Interview Feedback
- Student Dashboard
- Progress Tracking

## SHOULD HAVE

- Clean, professional dashboard UI with loading/error/empty states
- Re-analysis after resume improvement
- Persistent conversation context for the mentor
- Interview history

## BONUS

- GitHub analysis (P1 MCP)
- MCP-powered tools
- Lightweight RAG
- LinkedIn suggestions
- Voice interview
- AI cover letter
- Daily challenges

## OUT OF SCOPE

- Mobile application
- Payment system
- Full job marketplace
- Social network
- Large admin panel
- Custom foundation model
- Complex microservice architecture
- Unnecessary AI infrastructure

## Decision Rule

When time pressure appears, cut in this order: **BONUS → SHOULD HAVE → (never) MUST HAVE**. If a must-have is at risk, stop bonus work immediately and stabilize the must-have.
