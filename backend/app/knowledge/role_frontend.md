# Junior Frontend Engineer Skill Matrix

The junior frontend engineer is responsible for delivering accessible, responsive, performant, and intuitive client-side user interfaces that consume backend APIs and provide a smooth user experience across web browsers and devices.

## Must-Have Skills

### 1. Semantic HTML5 and Accessibility (a11y)
- **Proficiency Description**: Deep understanding of semantic HTML tags (`main`, `nav`, `section`, `article`, `header`, `footer`, `aside`, `dialog`). Familiarity with Web Content Accessibility Guidelines (WCAG) 2.1 AA standards, ARIA roles, keyboard navigation, and form labels.
- **Expectation**: Writes structured HTML that renders cleanly, passes screen-reader checks, and handles keyboard focus states natively without relying solely on `div` and `span` elements.

### 2. Modern CSS3 and Responsive Layouts
- **Proficiency Description**: Fluency with CSS Grid, Flexbox, the CSS Box Model, CSS custom properties (variables), media queries, and mobile-first design philosophy.
- **Expectation**: Converts design specifications (such as Figma or Adobe XD wireframes) into responsive layouts that adapt smoothly across mobile, tablet, and widescreen desktop viewports without horizontal scroll clipping.

### 3. Modern JavaScript (ES6+) Core Fundamentals
- **Proficiency Description**: Thorough understanding of JavaScript runtime behavior: closures, scope, prototypes, array transformations (`map`, `filter`, `reduce`), destructuring, spread/rest operators, asynchronous promises, and `async`/`await`.
- **Expectation**: Diagnoses DOM events, manages event bubbling and delegation, and debugs client-side issues using modern browser developer tools (Chrome DevTools, Firefox Developer Edition).

### 4. Component-Based Frameworks (React, Vue, or Angular)
- **Proficiency Description**: Strong hands-on competence with a prominent modern frontend library or framework, primarily React (version 18+). Understands component lifecycles, JSX syntax, unidirectional data flow, props, and standard React Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`).
- **Expectation**: Constructs modular, reusable functional components. Avoids unnecessary re-renders, manages form inputs cleanly, and implements conditional rendering safely.

### 5. API Integration and Asynchronous State Handling
- **Proficiency Description**: Consuming RESTful or GraphQL backend endpoints using native `fetch` or Axios.
- **Expectation**: Manages client-side asynchronous states robustly: loading spinners, skeleton screens, error boundaries, empty list states, and stale data invalidation.

### 6. Git and Package Management
- **Proficiency Description**: Familiarity with npm, pnpm, or yarn for dependency management, package scripts, and semantic versioning. Uses Git for branch workflows and pull request reviews.

## Nice-to-Have Skills

### 1. TypeScript for Frontend
- **Proficiency Description**: Writing typed components, defining interfaces for API responses and component props, and understanding type inference and union types.
- **Value**: Catches runtime null pointer errors at compile time and improves IDE autocomplete and code refactoring safety.

### 2. State Management Libraries
- **Proficiency Description**: Familiarity with global state managers such as Redux Toolkit, Zustand, or TanStack Query (React Query) for server-state caching.
- **Value**: Simplifies state synchronization across distant components and reduces duplicate network fetch calls.

### 3. Modern CSS Frameworks and Utility Tools
- **Proficiency Description**: Experience with Tailwind CSS, CSS Modules, or Styled Components for styled UI authoring.
- **Value**: Accelerates rapid prototyping while maintaining design system consistency.

### 4. Client-Side Testing
- **Proficiency Description**: Writing unit and component tests with Jest, Vitest, and React Testing Library.
- **Value**: Ensures components render correctly, fire event handlers as expected, and maintain accessibility compliance.

### 5. Web Performance and Core Web Vitals
- **Proficiency Description**: Understanding image optimization, lazy loading, code splitting with `React.lazy`, and Core Web Vitals (LCP, FID/INP, CLS).
- **Value**: Improves user retention and search engine indexability by keeping initial page loads fast.
