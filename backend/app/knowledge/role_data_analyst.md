# Junior Data Analyst Skill Matrix

The junior data analyst extracts, inspects, cleans, transforms, and models data to uncover actionable business insights, identify trends, and produce clear visual reports and dashboards for decision-makers.

## Must-Have Skills

### 1. Advanced SQL for Analytics
- **Proficiency Description**: High proficiency in data manipulation and querying using SQL. Understands inner and outer joins, unions, subqueries, Common Table Expressions (CTEs), aggregate functions, and window functions (`ROW_NUMBER()`, `RANK()`, `LEAD()`, `LAG()`, `SUM() OVER()`).
- **Expectation**: Writes performant queries against operational databases or data warehouses (PostgreSQL, BigQuery, Snowflake) to extract cohort metrics, retention rates, and revenue trends.

### 2. Spreadsheet Modeling (Microsoft Excel / Google Sheets)
- **Proficiency Description**: Mastery of spreadsheet calculations: Pivot Tables, `XLOOKUP`, `INDEX(MATCH)`, logical statements (`IF`, `IFS`, `COUNTIFS`, `SUMIFS`), conditional formatting, and chart generation.
- **Expectation**: Quickly audits raw CSV exports, checks data integrity, performs ad-hoc exploratory calculations, and formats executive summaries.

### 3. Business Intelligence and Visualization Tools
- **Proficiency Description**: Proficiency in building interactive dashboards with Power BI, Tableau, or Metabase.
- **Expectation**: Connects data sources, creates calculated measures or DAX expressions, builds responsive dashboards with appropriate visual elements (bar charts, line graphs, heatmaps, KPI cards), and optimizes visual hierarchies for non-technical stakeholders.

### 4. Data Cleaning and Transformation with Python or R
- **Proficiency Description**: Command of Python analytics libraries (Pandas and NumPy) or R (dplyr, tidyr).
- **Expectation**: Ingests messy datasets, identifies missing values and outliers, parses datetime strings, handles type coercion, reshapes tables using melt and pivot, and exports clean datasets for reporting.

### 5. Descriptive Statistics and Business Metrics
- **Proficiency Description**: Grasp of mean, median, mode, variance, standard deviation, interquartile ranges, correlation versus causation, and common business metrics (Customer Acquisition Cost - CAC, Lifetime Value - LTV, Churn Rate, Daily Active Users - DAU).
- **Expectation**: Communicates distributions accurately without misrepresenting skewed data with simple averages.

## Nice-to-Have Skills

### 1. Version Control and Data Documentation
- **Proficiency Description**: Managing SQL analysis scripts and Python notebooks via Git; maintaining data dictionaries and metadata documentation.
- **Value**: Ensures reporting is reproducible, peer-reviewed, and verifiable across quarterly reporting cycles.

### 2. Automated Reporting and ETL Scripts
- **Proficiency Description**: Writing Python scripts that pull data from REST APIs, clean the payload, and update warehouse tables or send email summaries automatically.
- **Value**: Reduces repetitive manual data extraction tasks and maintains updated dashboards without human intervention.

### 3. A/B Testing and Hypothesis Testing
- **Proficiency Description**: Understanding statistical significance, p-values, confidence intervals, sample size calculation, and two-sample t-tests.
- **Value**: Assists product and marketing teams in evaluating experimental feature rollouts objectively.
