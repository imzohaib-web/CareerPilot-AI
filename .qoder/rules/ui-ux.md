# CareerPilot AI — UI/UX Standards

CareerPilot must look like a professional AI career SaaS product — conveying career, AI, trust, progress, and professional development.

## Avoid

- Generic AI-generated dashboard appearance
- Excessive gradients or glassmorphism
- Random disconnected cards
- Inconsistent spacing or typography
- Unnecessary animations
- Placeholder/lorem content
- Demo-looking interfaces

## Require

- Consistent typography and spacing scale
- Clear visual hierarchy
- Responsive design (mobile, tablet, desktop)
- Accessibility (semantic HTML, contrast, keyboard/focus states)
- Loading states for every async view
- Error states with clear recovery actions
- Empty states that guide the next action
- Proper form validation with inline feedback
- Reusable components with clean boundaries
